# Solayre Quotes Leads plugin

Stateless CFE-receipt → solar-quote tools scoped to the solayre-leads agent. The current peer is assumed to be the lead receiving the quote; persistence in the leads DB stays in whatsapp-lead-bot via save_lead / save_receipt_data.

## Distribution

- Package: `@openclaw/solayre-quotes-leads`
- Install route: included in OpenClaw
